# Пабло — сайт гастропаба (Псков, Западная 1)

Статичный сайт. Никаких сборщиков и зависимостей — только HTML, CSS и один JS-файл.

## Ссылка для клиента

https://claude.ai/code/artifact/be7e87ed-2826-42d4-8bb0-4dcd4c6a4aaf

Артефакт по умолчанию **приватный** — прежде чем отправлять, откройте его и
нажмите «Поделиться». Это одностраничная сборка (`_site.html`, 9,8 МБ): весь
CSS, JS и картинки внутри одного файла, потому что артефакты не грузят внешние
ресурсы. Пересобрать после правок сайта — `node _artifact.js`, затем
опубликовать заново на тот же адрес.

Важно: не открывайте повторно доступ старому артефакту 4f78314d — там
закреплена устаревшая версия, и клиент увидит сайт без заглушки 18+.

## Посмотреть

```bash
node _serve.js
```

Откроется на http://localhost:5173. Можно и просто открыть `index.html` двойным
кликом — всё работает и из файла.

## Выложить в интернет

Залить папку целиком на любой хостинг статики (Netlify, Vercel, Cloudflare Pages,
GitHub Pages, обычный `/public_html` на шаред-хостинге). Точка входа — `index.html`.

## Как обновлять

Сначала главное: **быстро меняющееся на сайт намеренно не положено.**

| Что | Как часто | Где живёт |
|---|---|---|
| Меню обедов | каждый день | Только в ВК. Сайт ведёт туда ссылкой |
| Пивная карта | каждую неделю | Только на месте. Сайт говорит «уточняйте у бармена» |
| Цены кухни | 2–4 раза в год | `assets/data.js` |
| Барная карта | 2–4 раза в год | `assets/bar.js` |
| Фото блюд | редко | `img/dish/` + путь в `data.js` |
| Фото атмосферы | по желанию | `img/vk/` + список в `data.js` (`VENUE`) |

Поэтому «обновлять сайт» = раз в квартал поправить цены. Всё, что требует
ежедневного внимания, вынесено туда, где заведение и так работает.

### Поменять цену или описание — 2 минуты

`assets/data.js` отформатирован так, что **одно блюдо занимает одну строку**.
Найдите блюдо поиском по названию и поправьте число:

```
{"t":"Тако с говядиной","d":"...","p":490,"v":"290 г","img":"img/dish/6-14.jpg"}
                                        ^^^ вот цена
```

`p` — цена, `v` — вес, `d` — описание, `img` — путь к фото. Сохранить, обновить
страницу в браузере. Если правили много — прогнать `node _format-data.js`,
он вернёт файл к единому виду.

### Заменить фото блюда

Положить файл в `img/dish/` (имя латиницей, без пробелов) и вписать путь в поле
`img` нужной строки. Размер — от 600 px по короткой стороне, обрежется само.

### Добавить фото в галерею

Положить в `img/vk/`, добавить путь в `window.VENUE` в конце `data.js`.

### Собрать заново из ВК Маркета

Каталог `vk.ru/market-218921119` — это и есть панель управления клиента: он ведёт
его сам, цены там совпадают с печатным меню. Но **ВК не отдаёт данные скриптом** —
блокирует проверкой на робота, поэтому сбор идёт через браузер (так собран
`_vk-market.json`). Полная пересборка оправдана, только если переверстали всё меню;
для нескольких цен быстрее руками.

### После любой правки

```
node _artifact.js     # пересобрать одностраничник
```
затем опубликовать `_site.html` артефактом. Помните: посетители видят версию,
закреплённую в момент открытия доступа — после публикации проверьте ссылку
в приватном окне.

## Что стоит доделать

- **Пивная карта.** В фирменном меню она спрятана за QR-кодом, поэтому сортов
  разливного, баночного и бутылочного на сайте нет — только объяснение, что
  список живёт на месте. Пришлите ассортимент — добавим отдельной группой.
- **Мескалита.** Состав коктейля на фото не читается, поэтому у него указаны
  только объём и цена. Одна строка — и допишем.
- **Реальные фото веранды и трансляций** — сейчас взяты из отзывов гостей.
- **Форма брони.** Сейчас бронь ведёт на телефон и мессенджеры. Если нужна
  форма с отправкой — нужен бэкенд или сервис вроде Formspree.
