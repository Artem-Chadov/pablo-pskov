# «Пабло» — гастропаб в Пскове

Демосайт для разговора с владельцем. Живой адрес:
https://artem-chadov.github.io/pablo-pskov/

Папка содержит статический HTML, CSS и JavaScript. Локально сайт запускается командой node _serve.js; адрес — http://localhost:5173.

## Что где менять

- index.html — структура страницы, постоянные тексты, телефон и ссылки.
- assets/style.css — оформление и адаптив.
- assets/app.js — меню, галерея, статус работы, помощник, показ обеда и отзывов.
- assets/content.js — меняющиеся обеды и отзывы. Это отдельный файл, чтобы не искать их в разметке.
- assets/data.js — основное меню. _build.js его пересобирает и может перезаписать ручные правки.
- assets/bar.js — барная карта. _build.js её не трогает.

### Обед на конкретную дату

В assets/content.js найдите lunchByDate и добавьте дату в формате ГГГГ-ММ-ДД:

    lunchByDate: {
      '2026-10-01': [
        'Салат: точное название',
        'Суп: точное название',
        'Горячее: точное название и гарнир'
      ]
    }

Дату сайт определяет по московскому времени. В субботу и воскресенье меню дня не выводится. Если запись на сегодня отсутствует, сайт предлагает уточнить блюда по телефону или во ВКонтакте. Вчерашнее меню как сегодняшнее не показывается. Состав вносить только по подтверждённой публикации или словам заведения.

Время обедов 13:00–17:00 подтверждено Артёмом 30.09.2026. Цена 550 ₽ и вес около 640 г взяты из прежнего меню и перед показом владельцу требуют подтверждения.

### Отзывы

В том же файле массив reviews: у каждого отзыва есть author и text. Можно заменить текст, удалить объект или добавить новый по тому же образцу. На страницу он попадёт после сохранения и публикации файла. Сайт показывает выдержки из трёх публичных отзывов; ссылка в разделе ведёт к отзывам заведения на Яндекс Картах. Не приписывать гостю сочинённый текст.

## Перед предложением Эдуарду

Уточнить фактический состав и цену обедов, актуальность позиций меню и барной карты, часы работы, возможность мероприятий, контактные мессенджеры и реквизиты заведения. Пока этих подтверждений нет, сайт остаётся концептом.

Карта в контактах встроена через Яндекс; рядом есть прямая ссылка на маршрут. Кнопка события открывает WhatsApp с темой сообщения, ниже есть звонок. Бронь на сайте ведёт к звонку или мессенджеру; собственной формы бронирования нет.

## Публикация

После проверки локальной версии запустить _version.py, затем C:\Users\User\.claude\hooks\tools\ghpages.py по инструкции этого инструмента. Перед отправкой владельцу открыть публичную ссылку и проверить, что она отдаёт новую версию. Старый адрес /pablo/ возвращает 404.

Страница на GitHub Pages закрыта от поиска мета-тегом noindex при выкладке. В локальном index.html этого тега нет.
